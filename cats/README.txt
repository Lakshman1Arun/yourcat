Cat Expression Meme Images
===========================

Add your cat meme images to this folder (`cats/`).
You can use JPG, PNG, WEBP, or GIF images!

Expected filenames:

1. happy.jpg       - Happy / Smiling Cat meme
2. shocked.jpg     - Shocked / Mouth open Cat meme
3. angry.jpg       - Angry / Scowling Cat meme
4. sad.jpg         - Sad / Crying Cat meme
5. wink.jpg        - Smug / Winking Cat meme
6. sleepy.jpg      - Sleepy / Yawning / Napping Cat meme
7. silly.jpg       - Silly / Tongue Out / Blep Cat meme
8. kissy.jpg       - Kissy / Pouting / Duckface Cat meme
9. confused.jpg    - Confused / Raised Eyebrow Cat meme
10. disgusted.jpg  - Disgusted / Grossed out Cat meme
11. screaming.jpg  - Laughing / Screaming / Hysterical Cat meme
12. neutral.jpg    - Neutral / Staring / Judging Cat meme (default)

Tip: If you use .png or .webp files instead of .jpg, the app automatically checks and loads them!
